# Web Rotor (เว็บโรเตอร์) สำหรับ NVDA

ส่วนเสริมนี้เพิ่มเมนูหมุน (Rotor) แบบเดียวกับ VoiceOver Rotor ให้กับ NVDA เพื่อสำรวจองค์ประกอบ
ต่างๆ ของหน้าเว็บได้อย่างรวดเร็ว รองรับ 23 หมวดหมู่ เลือก/จัดลำดับหมวดหมู่เองได้ แต่ละหมวดหมู่เป็นแท็บ
พิมพ์ตัวอักษรเพื่อกระโดดไปยังรายการ คีย์ลัดกระโดดตรงไปแต่ละหมวดหมู่ (ทั้งแป้นอังกฤษและไทย) และรองรับ 2 ภาษา (อังกฤษ/ไทย)

ผู้พัฒนา: Peera Pilarit (peera@cfbt.or.th)
เวอร์ชัน: 1.8.1

---

## วิธีเรียกใช้งานโรเตอร์

1. เปิดหน้าเว็บใดๆ ในเบราว์เซอร์ที่ NVDA รองรับ (Chrome, Firefox, Edge เป็นต้น)
2. ตรวจสอบว่าอยู่ใน **Browse Mode** (โหมดเรียกดู) ไม่ใช่ Focus Mode
3. กด **Control+Windows+U** เพื่อเปิดเว็บโรเตอร์ (หรือ **NVDA+F7** ถ้าตั้งค่าให้ใช้แทน Elements List ไว้ — ดูหัวข้อ "วิธีเปิดหน้าตั้งค่า")

เมื่อเปิดขึ้นมา โฟกัสจะอยู่ที่ **รายการของหมวดหมู่แรก** ทันที ใช้ลูกศรขึ้น/ลงหรือพิมพ์ตัวอักษรได้เลย
หมวดหมู่แต่ละหมวดเป็นแท็บหนึ่งแท็บ อยู่เหนือรายการ

## คีย์ลัดภายในหน้าต่างเว็บโรเตอร์

| ปุ่ม | หน้าที่ |
|---|---|
| ลูกศรขึ้น / ลง | เลื่อนดูรายการภายในหมวดหมู่ปัจจุบัน |
| พิมพ์ตัวอักษร (ในรายการ) | กระโดดไปยังรายการถัดไปที่ขึ้นต้นด้วยตัวอักษรนั้น กดตัวเดิมซ้ำเพื่อวนไปรายการถัดไป พิมพ์หลายตัวต่อกันเร็วๆ เพื่อค้นหาเป็นคำ ใช้ได้ทั้งตัวอักษรไทยและอังกฤษ ถ้าไม่พบจะมีเสียงบี๊บสั้น |
| ลูกศรซ้าย / ขวา (ในรายการ) | เปลี่ยนหมวดหมู่ (วนไปตามลำดับที่ตั้งค่าไว้) NVDA จะอ่านชื่อหมวดหมู่ จำนวนรายการ และรายการแรก |
| Shift+Tab (จากรายการ) | ไปยังแท็บหมวดหมู่ ใช้ลูกศรซ้าย/ขวาเลือกแท็บ แล้วกด Tab เพื่อกลับเข้ารายการของหมวดนั้น |
| **Alt+ตัวอักษร** | กระโดดตรงไปยังหมวดหมู่นั้นทันที (ดูตารางด้านล่าง) ใช้ได้ทั้งแป้นอังกฤษและแป้นไทย จากทุกจุดในหน้าต่าง |
| **Enter** หรือ **Space** | กระโดดไปยังตำแหน่งที่เลือกในเอกสาร แล้วปิดหน้าต่าง — **Enter ใช้ได้จากทุกจุดในหน้าต่าง** ทั้งที่แท็บและในรายการ |
| Esc | ปิดหน้าต่างโดยไม่ทำอะไร |

**ปุ่มลัดอื่นของ NVDA ยังทำงานได้ตามปกติขณะเว็บโรเตอร์เปิดอยู่ (ค่าเริ่มต้น)** มีตัวเลือกในหน้าตั้งค่า
ให้บล็อกคำสั่งอื่นของ NVDA ชั่วคราวได้ (**ปิดเป็นค่าเริ่มต้น**) — ดูรายละเอียดในหัวข้อ "วิธีเปิดหน้าตั้งค่า" ด้านล่าง

## ตารางคีย์ลัด Alt+ตัวอักษร ต่อหมวดหมู่

ใช้ได้ทั้งสองชุดเสมอ ไม่ขึ้นกับภาษาที่ตั้งค่าไว้: ถ้าแป้นพิมพ์เป็นภาษาอังกฤษ ใช้คอลัมน์ English
ถ้าแป้นพิมพ์เป็นภาษาไทย ใช้คอลัมน์ไทย ไม่ต้องสลับแป้นพิมพ์ก่อนกด

|---|---|---|
| หัวเรื่อง / Headings | Alt+H | Alt+ห |
| ลิงก์ (ทั้งหมด) / Links | Alt+K | Alt+ล |

| ลิงก์ที่ยังไม่เยี่ยมชม / Unvisited links | Alt+U | Alt+ค |
| จุดสังเกต / Landmarks | Alt+D | Alt+จ |
| จุดสังเกตหลัก / Main landmark | Alt+M | Alt+ง |
| ปุ่ม / Buttons | Alt+B | Alt+ป |
| ช่องแบบฟอร์ม (ทั้งหมด) / Form fields | Alt+O | Alt+ช |
| ช่องพิมพ์ข้อความ / Edit fields | Alt+E | Alt+ฉ |
| Checkbox | Alt+X | Alt+ซ |
| Radio button | Alt+R | Alt+ญ |
| Combo box | Alt+C | Alt+ฎ |

## หมวดหมู่ที่รองรับ (23 หมวด)

หัวเรื่อง, ลิงก์ (ทั้งหมด/เคยเยี่ยมชม/ยังไม่เยี่ยมชม), จุดสังเกต, จุดสังเกตหลัก,
ปุ่ม, ช่องแบบฟอร์ม (ทั้งหมด), ช่องพิมพ์ข้อความ, checkbox, radio button, combo box,
ตาราง, รายการ, รายการย่อย, รูปภาพ/กราฟิก, ข้อความอ้างอิง, เฟรม, เส้นแบ่ง,
อ็อบเจกต์ฝังตัว, หมายเหตุ/ข้อคิดเห็น, ย่อหน้า, บทความ

ค่าเริ่มต้นเปิดใช้งาน 7 หมวดแรก (หัวเรื่อง, ลิงก์, จุดสังเกต, ปุ่ม, ช่องแบบฟอร์ม, ตาราง, รายการ)
เพื่อไม่ให้เมนูยาวเกินไปในการใช้งานทั่วไป — เพิ่มหมวดอื่นๆ ได้เองผ่านหน้าตั้งค่า

## ภาษาที่ใช้แสดงผล

ค่าเริ่มต้นของส่วนเสริมนี้คือ **ภาษาอังกฤษ** (แยกต่างหากจากภาษาที่ใช้แสดงผลของ NVDA เอง) เปลี่ยนเป็น
ภาษาไทยได้ที่หน้าตั้งค่าเว็บโรเตอร์ การเปลี่ยนภาษาจะมีผลตั้งแต่ครั้งถัดไปที่เปิดเว็บโรเตอร์หรือหน้าตั้งค่า

ตัวอักษร mnemonic ของช่องต่างๆ ในหน้าตั้งค่าจะเปลี่ยนไปตามภาษาที่เลือก ส่วนคีย์ลัด Alt+ตัวอักษร
ต่อหมวดหมู่ในหน้าต่างโรเตอร์ใช้ได้ทั้งชุดอังกฤษและชุดไทยเสมอ

## วิธีเปิดหน้าตั้งค่า

มี 2 วิธี:

- กด **Control+Windows+Shift+U**
- หรือไปที่เมนู NVDA (NVDA+N) > Preferences > **ตั้งค่าเว็บโรเตอร์... (Web Rotor)**

### สิ่งที่ปรับได้ในหน้าตั้งค่า

- **ช่องเลือกภาษา** (mnemonic: Alt+L / Alt+ภ) — เลือกให้เว็บโรเตอร์แสดงผลเป็น **English** (ค่าเริ่มต้น) หรือ **ไทย**
- **รายการหมวดหมู่** (mnemonic: Alt+C / Alt+ห) — ติ๊กถูก/ไม่ติ๊ก เพื่อเปิด/ปิดหมวดหมู่นั้นในโรเตอร์
- **ปุ่มเลื่อนขึ้น** (Alt+U / Alt+ข) และ **เลื่อนลง** (Alt+D / Alt+ล) — จัดลำดับการหมุน (ลำดับในลิสต์ = ลำดับที่จะเจอเมื่อกดลูกศรขวาในโรเตอร์)
- **ปุ่มคืนค่าเริ่มต้น** (Alt+R / Alt+ค) — กลับไปใช้ 7 หมวดหมู่มาตรฐาน
- **ช่องติ๊ก "ใช้ NVDA+F7 เปิดเว็บโรเตอร์ แทน Elements List มาตรฐานของ NVDA"** — ถ้าเปิดไว้ การกด NVDA+F7
  จะเปิดเว็บโรเตอร์แทนกล่องโต้ตอบ Elements List เดิมของ NVDA ทันที (ค่าเริ่มต้น**ปิด** เพื่อไม่ให้พฤติกรรม
  มาตรฐานของ NVDA เปลี่ยนไปโดยไม่ได้ตั้งใจ)
- **ช่องติ๊ก "บล็อกคำสั่งอื่นของ NVDA ขณะเว็บโรเตอร์เปิดอยู่"** — ค่าเริ่มต้น**ปิด**
  เมื่อเปิดไว้ คำสั่งของ NVDA ที่ใช้ปุ่ม NVDA, Control หรือ Windows (เช่น NVDA+F7, NVDA+T) จะถูกปิดชั่วคราว
  ส่วนปุ่มที่ใช้ในเว็บโรเตอร์ (ลูกศร ตัวอักษร Alt+ตัวอักษร Tab Enter Esc) ยังทำงานตามปกติ
  และถ้าสลับไปหน้าต่างอื่น การบล็อกจะไม่มีผล (เวอร์ชัน 1.8.0 และก่อนหน้ามีปัญหาว่าตัวเลือกนี้บล็อกทุกปุ่ม
  จน NVDA เงียบและปิดหน้าต่างไม่ได้ รวมถึงหน้าตั้งค่า แก้แล้วในเวอร์ชัน 1.8.1 ตัวเลือกนี้ไม่มีผลกับหน้าตั้งค่าอีกต่อไป)

ค่าที่ตั้งทั้งหมดจะถูกบันทึกไว้ถาวรและมีผลกับการเปิดโรเตอร์/กด NVDA+F7 ครั้งถัดไป

### หมายเหตุเรื่อง NVDA+F7

ฟีเจอร์นี้อาศัยกลไกที่ Global Plugin ของ NVDA มีสิทธิ์ตัดหน้า (override) ปุ่มลัดที่โหมดเรียกดู (Browse Mode)
ผูกไว้อยู่แล้วได้ตามการออกแบบมาตรฐานของ NVDA ซึ่งใช้งานได้กับผู้ใช้ส่วนใหญ่ แต่หากทดสอบแล้วพบว่า
NVDA+F7 ยังคงเปิด Elements List เดิมอยู่แม้ติ๊กเปิดตัวเลือกนี้ไว้ สามารถผูกปุ่มลัดเองแบบชัวร์ 100% ได้ผ่าน
**NVDA+N > Preferences > Input gestures**: ค้นหา "Web Rotor" แล้วผูกปุ่ม NVDA+F7 ให้กับคำสั่ง
"เปิด Elements List มาตรฐานของ NVDA หรือเว็บโรเตอร์..." (และหากต้องการ อาจยกเลิกปุ่ม NVDA+F7 ออกจาก
คำสั่ง "Lists various types of elements..." ในหมวด Browse mode ด้วย)

## หมายเหตุทางเทคนิค

ส่วนเสริมนี้ใช้เมธอดภายในของ NVDA ชื่อ `treeInterceptor._iterNodesByType()` ซึ่งเป็นกลไกเดียวกับ
ที่ใช้ในกล่องโต้ตอบ Elements List มาตรฐาน (NVDA+F7) จึงทำงานได้กับทุกเว็บเบราว์เซอร์ที่ NVDA รองรับ
Browse Mode อยู่แล้ว โดยไม่ต้องแก้ไขหรือแตะต้องหน้าเว็บใดๆ

บางหมวดหมู่ที่เพิ่มเข้ามาใหม่ (เช่น ย่อหน้า, บทความ, เฟรม) อาจไม่มีรายการให้แสดงในบางเว็บไซต์หรือ
เบราว์เซอร์บางตัว เนื่องจากขึ้นอยู่กับว่าเบราว์เซอร์นั้นๆ รายงานโครงสร้างของหน้าเว็บให้ NVDA ทราบครบถ้วน
แค่ไหน ถือเป็นพฤติกรรมปกติ ไม่ใช่ข้อผิดพลาด

หน้าเว็บที่มีองค์ประกอบมากเกิน 2,000 รายการในหมวดเดียวกัน จะถูกตัดไว้ที่ 2,000 รายการแรก เพื่อป้องกัน
ไม่ให้การดึงรายการที่มากเกินไปทำให้ NVDA ค้าง

การบล็อกปุ่มลัดอื่นชั่วคราว (ตัวเลือกในหน้าตั้งค่า) ใช้ extension point ของ NVDA ชื่อ
`inputCore.decide_executeGesture` (มีตั้งแต่ NVDA 2023.2 เป็นต้นไป) หากติดตั้งบน NVDA รุ่นเก่ากว่านี้
ฟีเจอร์นี้จะถูกข้ามไปโดยอัตโนมัติ แต่โรเตอร์เองยังใช้งานได้ตามปกติ

คีย์ลัด Alt+ตัวอักษรในหน้าต่างโรเตอร์ ตรวจตัวอักษรไทยของปุ่มที่กดตามแป้นพิมพ์ที่ใช้อยู่ก่อน
ถ้าตรงกับตารางไทยจะใช้หมวดตามตารางไทย ถ้าไม่ตรงจะใช้ตัวอักษรอังกฤษบนปุ่มนั้นแทน
(เช่น แป้นไทยกด Alt+ปุ่ม S ซึ่งเป็น "ห" จะไปหมวดหัวเรื่อง)

## การปรับแต่งเพิ่มเติมที่ทำได้ในอนาคต

- เพิ่มหมวดหมู่ใหม่ (เช่น ข้อผิดพลาดในการสะกดคำ) โดยแก้ที่ `categories.py` และ `strings.py`
- ปรับปุ่มลัดหลัก (Ctrl+Win+U ฯลฯ) เองผ่าน NVDA Input Gestures dialog (Preferences > Input gestures)
- แสดงตัวอักษรคีย์ลัด Alt+ต่อหมวดหมู่ไว้ในหน้าจอโรเตอร์เอง (ปัจจุบันอยู่ในเอกสารนี้เท่านั้น)
